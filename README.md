# 🌍 ویت‌لایف — شبیه‌ساز زندگی در تلگرام

مینی‌اپ بازی «از تولد تا مرگ» — هر انتخابی سرنوشت را عوض می‌کند: شغل، عشق، ثروت، جرم، زندان، خاندان و نسل‌های بعدی.

- 🎮 **بازی:** [@waitlife_game_bot](https://t.me/waitlife_game_bot)
- 🌐 **سرور:** https://waitlife-server.onrender.com
- 🗄️ **دیتابیس:** Neon (پلن رایگان) — بدون دیتابیس هم با فایل محلی کار می‌کند

---

## 🗂️ ساختار پروژه

```
waitlife-server/
├── server.js              ← نقطهٔ ورود (راه‌اندازی دیتابیس، وب‌هوک، زمان‌بندی‌ها)
├── public/
│   └── index.html         ← خود بازی (تنها فایلی که برای تغییر بازی لازم است)
├── src/
│   ├── config.js          ← تنظیمات سراسری + بسته‌های فروش + ثابت‌های اقتصاد
│   ├── app.js             ← اپلیکیشن Express — همهٔ مسیرها اینجا سوار می‌شوند
│   ├── db.js              ← لایهٔ داده: پستگرس/فایل + محاسبهٔ ثروت و امتیاز سمت سرور
│   ├── auth.js            ← احراز هویت تلگرام (امضای HMAC) + دروازه‌های پنل ادمین
│   ├── telegram.js        ← API پایهٔ بات، پیام‌ها، لینک دعوت، وب‌هوک
│   ├── bot.js             ← مغز بات: پرداخت استارز، دکمه‌های تأیید، دستورهای مدیر
│   ├── backup.js          ← پشتیبان‌گیری خودکار — فایل فشرده در چت تلگرام مدیر
│   ├── auction.js         ← حراج هفتگی + ساعت جهان
│   ├── notify.js          ← اعلان هوشمند (غیبت طولانی، افت رتبه)
│   ├── refs.js            ← سیستم دعوت دوستان
│   ├── middleware.js      ← gzip، محدودیت نرخ، پیدا کردن فایل بازی
│   ├── util.js            ← ابزارهای کوچک مشترک
│   ├── routes-core.js     ← سلامت | ورود | ذخیرهٔ ابری | رتبه‌بندی
│   ├── routes-world.js    ← جهان مشترک (ارواح، رویدادها، برخوردها)
│   ├── routes-shop.js     ← فروشگاه (کارت‌به‌کارت، استارز، دعوت)
│   └── routes-admin.js    ← پنل مدیریت کامل
├── test/
│   └── server.test.js     ← تست‌های خودکار (بدون نیاز به توکن یا دیتابیس)
└── package.json
```

## 🚀 اجرای محلی

```bash
npm install
npm start          # حالت فایل (بدون دیتابیس) — پورت 3000
npm test           # تست‌های خودکار
```

برای حالت توسعه (احراز هویت ساختگی برای تست بدون تلگرام):

```bash
DEV_MODE=1 npm start
```

## ☁️ استقرار روی Render + Neon

متغیرهای محیطی مورد نیاز در پنل Render:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکنی که BotFather می‌دهد |
| `ADMIN_IDS` | شناسهٔ عددی تلگرام مدیر (برای چند نفر با ویرگول جدا کن) |
| `DATABASE_URL` | آدرس اتصال دیتابیس Neon |
| `SELF_URL` | آدرس سایت خودت (برای وب‌هوک و بیدار ماندن) — اختیاری ولی توصیه می‌شود |
| `BACKUP_HOURS` | فاصلهٔ پشتیبان‌گیری خودکار (پیش‌فرض: ۲۴) — اختیاری |

- **Build Command:** `npm install`
- **Start Command:** `npm start`

⚠️ بدون `DATABASE_URL` داده‌ها روی فایل ذخیره می‌شوند و در سرویس رایگان Render با هر ری‌استارت پاک می‌شوند.

## 🛠️ دستورهای مدیر در چت بات

| دستور | کار |
|---|---|
| `/pending` | سفارش‌های در انتظار تأیید |
| `/stats` | آمار کلی |
| `/backup` | پشتیبان فوری |
| `/backupinfo` | وضعیت پشتیبان‌گیری خودکار |
| `/on` و `/stop` | روشن/خاموش کردن اعلان‌ها |

تأیید/رد سفارش کارتی هم با دکمه‌های شیشه‌ای داخل همان پیام رسید انجام می‌شود.

## 💰 پرداخت

- **ستارهٔ تلگرام ⭐** — خودکار و آنی (برای کاربران خارج از ایران)
- **کارت‌به‌کارت 🧾** — کاربر رسید می‌فرستد، مدیر تأیید می‌کند

هر ستاره = ۳٬۵۰۰ تومان (قابل تغییر از پنل ادمین، بخش اقتصاد).

## 💾 پشتیبان‌گیری خودکار

هر `BACKUP_HOURS` ساعت، یک نسخهٔ کاملِ فشرده از دیتابیس به‌صورت فایل برای مدیر در تلگرام فرستاده می‌شود. اگر سرور یا دیتابیس از دست برود، همه‌چیز در چت تلگرام موجود است.

## 🔒 نکته‌های امنیتی

- هویت کاربران با امضای HMAC خود تلگرام تأیید می‌شود — جعل‌ناپذیر.
- ثروت و امتیاز رتبه‌بندی **سمت سرور** از روی ذخیرهٔ بازی محاسبه می‌شود؛ کلاینت نمی‌تواند عدد جعلی بفرستد.
- همهٔ مسیرهای `/api` محدودیت نرخ دارند (۹۰ درخواست در دقیقه).
- اقدام‌های حساس مدیر در دفتر رویداد (audit) ثبت می‌شود.
